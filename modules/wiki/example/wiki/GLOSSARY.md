# Glossary

Shared vocabulary for every agent that works with this wiki. Rules: `AGENTS.md` §11. One sentence per definition; list alternatives under `_Avoid_`.

## Terms

**Base Recipe**:
The recipe as written, for the number of servings its author gave.
_Avoid_: original recipe, default recipe

**Serving**:
The amount of a dish for one person.
_Avoid_: portion, helping

## Flagged ambiguities

- "Scale" meant both "change the servings" and "convert the units". Resolved on 2026-01-10: scale means only "change the servings"; the other is "convert".
